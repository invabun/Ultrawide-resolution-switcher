QUICK START GUIDE
==================

As of v2.0 there is NO setup step. Nothing gets downloaded.

Which file to run?
------------------
Double-click either one:
  - dist\Dota2ResolutionSwitcher.exe     (recommended)
  - switch_resolution.bat                (runs the script directly)

Do NOT double-click .ps1 files - they open as text instead of running.

Use it
------
Double-click to toggle 5120x1440 <-> 2560x1440.
The window closes automatically. Your refresh rate is kept.

Stuck at 60Hz after a driver update?
------------------------------------
Open PowerShell in this folder and run:
  .\SetRefreshRate.ps1 -List
  .\SetRefreshRate.ps1 -Hz 165
